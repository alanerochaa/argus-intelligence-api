Sobre a API

ARGUS Intelligence API

Microserviço Java responsável por gerenciar biomas, regiões, focos de calor e alertas operacionais.

Consome dados da NASA FIRMS, persiste no Oracle, publica eventos via RabbitMQ e integra IA para apoio à análise ambiental.
