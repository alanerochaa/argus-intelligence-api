ARGUS Intelligence API

Central técnica de monitoramento ambiental

Microserviço Java responsável por ingestão de dados ambientais, geração de alertas, análise de risco, mensageria e integração com os módulos de IA, Operations .NET e Mobile.

Visão executiva

ARGUS Intelligence API

Camada de inteligência ambiental do ecossistema ARGUS, responsável por centralizar dados de biomas, regiões, focos de calor, alertas e criticidade operacional.

O fluxo da solução conecta dados externos da NASA FIRMS, persistência em Oracle, eventos assíncronos via RabbitMQ e CloudAMQP, apoio analítico por IA, operação em C#/.NET e consumo pelo aplicativo mobile dos brigadistas.

Spring Boot Oracle NASA FIRMS RabbitMQ CloudAMQP IA .NET Mobile OpenAPI Azure
Hub operacional da arquitetura

Health Check

Verifica disponibilidade da API Java, banco, RabbitMQ e componentes monitorados pelo Actuator.

Status NASA FIRMS

Valida a integração externa responsável pelo consumo dos focos de calor monitorados por satélite.

Status API IA

Verifica a camada analítica responsável por apoiar a classificação de risco e criticidade dos alertas.

Status Operations .NET

Valida a integração com a API operacional responsável por ocorrências, brigadas e recursos.

Mensageria

RabbitMQ local no desenvolvimento e CloudAMQP como broker gerenciado no ambiente cloud.

Mobile ARGUS

Interface de campo para brigadistas acompanharem alertas, ocorrências e resposta operacional.
Documentação técnica

Swagger

Interface interativa para testar endpoints, validar contratos e demonstrar o comportamento da API.

OpenAPI JSON

Contrato técnico padronizado dos recursos REST expostos pela ARGUS Intelligence API.

Actuator

Monitoramento técnico da aplicação, health checks e indicadores operacionais da API.
Domínios de negócio ARGUS

Alertas

Eventos de risco gerados a partir dos focos de calor e utilizados para resposta operacional.

Biomas

Cadastro ambiental base para segmentação territorial e análise de risco por região monitorada.

Regiões

Áreas monitoradas vinculadas aos biomas e utilizadas na consolidação dos alertas ambientais.

Focos de Calor

Pontos de calor detectados, registrados e utilizados como insumo para geração de alertas.

Risco Ambiental

Motor analítico responsável por calcular criticidade operacional considerando nível de risco, focos de calor e condições climáticas.
